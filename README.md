# Cosmos 七视角国内风格基模：Iteration 3000

这是一个公开的静态展示站点，包含
`boshi_1000clips_sevenview_neighbor_i2v_v2` 在第 3,000 步生成的五条固定验证推理结果。
站点另设 `nuplan.html`，并列展示 nuPlan 六视角 Neighbor-v2 的
720p Iteration 10,000、480p Iteration 4,000 固定验证结果，以及
HDMap + 3D BBox 逐视角控制分支的 Iteration 7,000 固定推理结果。

## 内容

- 模型任务：七视角 image-to-video
- 多视角机制：每个视角与自身及左右相邻视角交互
- 文本条件：不使用
- 展示样例：5 条七视角拼接视频
- 页面入口：`index.html`
- nuPlan 六视角对比页：`nuplan.html`

## 训练资源与时间（2026-09-20 核验）

- 2 节点 × 16 张 PPU-ZW810E = 32 卡；每节点 176 CPU / 1,758 GiB RAM。
- CP8 × DP4，全局 batch 4；七视角、每视角29帧720p，固定单首帧，无场景文本。
- 官方2B权重初始化、约20.59亿参数全量微调、Neighbor-v2，学习率1e-5。
- 到3,000步累计训练阶段墙钟119,636秒，约33小时14分钟。
  首段0→1,000为39,401秒，续训1,000→3,000为80,235秒；包含中间2,000步保存/推理，
  不含排队、训练前初始化、两段间停顿以及3,000步后的保存/推理。
- 两次训练开始至目标更新完成的日志时间：09-16 01:55:47→12:52:28、
  09-16 16:38:11→09-17 14:55:26（同一日志时钟；日期为2026年）。
  全跨度含中断约37小时，不能当作纯训练耗时。
- 连续步日志间隔（排除≥120秒）平均39.37秒，中位39秒，仅代表常规迭代速度。
- 首段保存1,000步后固定推理失败，修复后从1,000步完整续训；当前保存指针为3,000。
  后续训练日志至少记录到iteration3510，配置上限10,000，不代表已完成10,000步。
- 本轮发现五条已发布视频本来就与指定3,000步源文件一致；逐文件SHA-256验证通过，
  不重复提交相同二进制，更新页面训练信息并添加版本查询参数避免沿用旧浏览器缓存。
